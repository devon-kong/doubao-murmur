## 2. 当前进展

### 已完成的功能改造与验证

- 原始“单独右 Option 按下并释放”触发已移除；当前 `HotkeyManager` 通过保留的 `CGEventTap` 监听精确 `⌃ + /`：ANSI `/` 的 keyCode 为 `44`，主修饰键集合必须恰好为 `.maskControl`，识别后 `return nil` 消费事件。
- 仍保留 `0.3s` 快捷键防抖和原有 ESC 取消逻辑。未加入自动重复键过滤等额外优化；用户要求“够用即可”。
- 实现了原生豆包输入法 bridge：
  - `InputSourceManager.swift` 用 macOS 公共 TIS API 选择 `com.bytedance.inputmethod.doubaoime.pinyin`；
  - `InputMethodSessionManager.swift` 让 Overlay 内的 `NSTextView` 成为输入客户端，并合成 Fn 按下/释放，启动/停止豆包输入法语音；
  - 结束时等待文本稳定，再通过 `PasteHelper` 写入剪贴板并合成 `⌘V`；
  - 保存并恢复用户先前的输入法；ESC 会取消而不粘贴。
- 关键时序是已实机试出的值：输入源 settle `0.15s`，Fn 启动 `0.10s`，最终文本 quiet period `0.35s`，安全超时 `1.5s`，剪贴板写入到模拟粘贴 `0.25s`。曾把粘贴延迟降到 `0.15s`，会粘贴上一次/上上次文本；`0.25s` 已由用户验证稳定。不要擅自再次缩短。
- 修复了 Overlay 打开时短暂闪现上一轮文本的问题：开始会话时同步清空 `NSTextView`。
- 用户已确认：在网易 UU 全屏状态下，`⌃ + /` 可显示输入框、可完成语音输入、二次按键可关闭、文本可复制并粘贴到远端目标输入框。

## 4. 关键发现

1. **当前正式功能实现不依赖 Web ASR。**
   `DoubaoMurmurApp.swift` 只实例化 `InputMethodSessionManager`，不是 `TranscriptionManager`。因此下面旧 Web ASR 文件在 bridge 现行链路中没有调用点，是 macOS-only 精简的候选：

   ```text
   doubao-murmur/ASRParamsStore.swift
   doubao-murmur/AudioCaptureManager.swift
   doubao-murmur/DoubaoASRClient.swift
   doubao-murmur/TranscriptionManager.swift
   doubao-murmur/WebViewManager.swift
   doubao-murmur/Resources/inject-dom.js
   doubao-murmur/Resources/inject-websocket.js
   ```

   删除前应从干净 `origin/master` 基线构建 Release；删除后再构建一次并执行基本功能回归。不要只根据文件名删除。

2. **主工作区不能合并/覆盖。**
   它比远端落后一个提交且包含与最终 bridge 冲突的本地修改/删除。最终“只留一个目录”的正确方式不是在这里强行 pull，而是以 `origin/master` 创建干净基线、完成清理并验证后，再以可恢复方式替换主目录。

3. **发布 worktree 是源码正确的基线，但本身不是最终目录。**
   它源代码干净、`HEAD=dfe484b`，但有 `305 MB` 构建缓存与生成项目；用户希望最终只留一个目录，因此它应在最终替换完成后移除，而不是把它直接 rename 成主目录（其 `.git` worktree 指针会随路径变化失效）。

4. **构建体积与运行内存不能混淆。**
   正式 `.app` bundle 为 `760 KB`；系统框架动态链接，不包含在 bundle 内。此前运行中的旧 V0.2 测试 App RSS 为 `37,056 KiB`（约 `36.2 MiB`），但交接时没有相关 App 在运行，所以这不是当前正式 App 的精确测量。不要报告 macOS 的 VSZ（约数百 GB）为实际内存。

5. **`UpdateChecker.swift` 仍指向原上游。**
   它硬编码 `lilong7676/doubao-murmur` 和 `Doubao-Murmur-<tag>.zip`。仓库已经脱离 fork，因此若未来保留“检查更新”功能、改仓库 slug 或发布新版本，应同步改它及 `.github/workflows/release.yml`；这不是当前清理前必须做的功能改动。

6. **名称尚未确定。**
   `Murmur Bridge` 只是建议。不要私自改 `PRODUCT_NAME`、`CFBundleDisplayName`、GitHub 仓库名或 Bundle ID。
