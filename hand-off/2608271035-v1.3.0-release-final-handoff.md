## 三、本轮核心实现

### 豆包输入法会话

- 兼容模式和快速模式共用 `RecordingReadinessGate` 和 `MarkedTextCommitGate`。
- overlay first responder 与豆包输入源确认并行，成功后只发送一次 Fn-down。
- 第二次热键发送 Fn-up；本轮必须真实观察 marked text `true -> false`，才在下一次主线程
  事件循环锁定文字。
- 从未出现 marked text 或 marked text 永不消失时，系统按设计停在 `stopping`；ESC 或应用
  退出负责取消和恢复。

### UU 快速模式 protocol v2

- 每笔订单使用 `requestId + controllerSessionId + sequence`。
- ACK 可以逆序返回，控制端按完整订单身份独立归属。
- 单笔超时或异常为 `unconfirmed`，不自动重试，也不再阻断后续订单。
- helper 在主线程串行执行剪贴板写入、前台 PID 复查和一次 Command-V。
- protocol v2 不兼容旧 helper；控制端与 Mac mini helper 必须配套升级。

### 诊断日志
